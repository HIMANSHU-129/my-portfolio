## ⚡ Architecture & Key Features

- **Sub-Second Core Web Vitals**: Zero cumulative layout shift (0.00 CLS), optimized Largest Contentful Paint (LCP), and minimal JavaScript client hydration.
- **Interactive Constellation Canvas**: Custom HTML5 Canvas particle physics with magnetic mouse repulsion and dynamic filament lines.
- **Infinite Brand Marquee**: Smooth GPU-accelerated scrolling tech strip showcasing 16 core tools with authentic brand palettes on hover.
- **Developer Journey Timeline**: Scroll-driven milestone timeline documenting self-taught beginnings, real production projects, and current engineering roles.
- **Dual-Mode Enquiry Console**: Full HTTP dispatch form supporting both interactive client UI and structured live JSON payload schemas.
- **Digital & Printable CV (`/resume`)**: Executive resume with photo, academic credentials (Xavier Institute of Engineering), key projects, and print-to-PDF formatting.
- **Terms & Usage Guidelines (`/terms`)**: Transparent usage and intellectual property documentation.

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/HIMANSHU-129/my-portfolio.git
cd my-portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Build for production:

```bash
npm run build
npm run start
```
